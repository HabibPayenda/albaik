# 05 — The hair-profile metric value shows in the guided-selection panel

**What to build:** When a hair profile has a metric value, the guided-selection panel shows it as the headline statistic, with its metric label as the supporting text. When the metric value is blank, the panel falls back to naming the matched product — the behaviour the field's own dashboard hint already promises.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] A profile with a metric value shows that value as the panel's headline, with its label.
- [ ] A profile with no metric value falls back to the matched product (current behaviour).
- [ ] Switching profiles updates the panel correctly in both cases.

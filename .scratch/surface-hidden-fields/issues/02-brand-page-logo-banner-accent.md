# 02 — The brand page uses the brand's logo, banner and accent

**What to build:** On a brand page the hero uses the brand's own artwork and colour: the banner image becomes the hero backdrop, the logo shows beside the brand name, and the brand's accent tints the hero. Each falls back gracefully — no banner keeps the royal gradient, no logo simply shows none — so a half-filled brand still looks finished. This also gives the shared page hero an optional backdrop, which the collection page reuses.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] The brand's logo appears in the hero beside the name, and is absent when none is set.

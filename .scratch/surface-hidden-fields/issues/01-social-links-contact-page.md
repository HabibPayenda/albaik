# 01 — Social links on the Contact page

**What to build:** A visitor on the Contact page sees a "Follow Albaik" row of the social networks configured in Settings, inside the Contact details card just under the WhatsApp and Email buttons. A network with no usable URL stays hidden, so the row never shows a broken or empty link. (The footer already shows the same networks through the same URL normaliser.)

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] The Contact details card shows the configured social networks, each linking to the right destination.
- [ ] A network with no URL — or a value that is not a usable URL — is not shown.
- [ ] A bare domain and a full URL both resolve to a working link.

# 04 — Search suggestion chips become a setting

**What to build:** The suggestion chips shown in the search overlay are edited from the dashboard instead of being hardcoded. Staff change the chips from a settings value and the search overlay reflects it, with the current chips as the fallback so it never looks empty.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Search overlay chips read from a dashboard-editable setting.
- [ ] An empty setting falls back to the current chips rather than showing nothing.
- [ ] The dashboard exposes the setting in an obvious place for staff.

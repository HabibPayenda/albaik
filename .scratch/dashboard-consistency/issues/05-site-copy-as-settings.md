# 05 — Site-owned copy becomes settings

**What to build:** The product-page tab labels, the "All formulas" filter chip, and the contact-form labels are editable from the dashboard instead of being hardcoded. Each reads from a dashboard-editable setting with the current text as its default, so nothing changes until staff choose to edit it.

**Blocked by:** None — can start immediately.

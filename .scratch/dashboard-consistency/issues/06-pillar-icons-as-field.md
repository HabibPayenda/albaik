# 06 — Trust pillar icons become an editable field

**What to build:** Each trust pillar's icon is chosen in the dashboard from the icon library and rendered from data on the public approach section, instead of a fixed icon mapping in code. Pillars without a chosen icon still render so a half-built pillar never looks broken.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Staff can pick a pillar's icon from the icon library in the dashboard.
- [ ] The public approach section renders each pillar's chosen icon from data.
- [ ] A pillar with no chosen icon renders a sensible fallback.
